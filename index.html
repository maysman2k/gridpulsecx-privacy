GridPulseCX Privacy Policy

Effective date: 12 October 2026

GridPulseCX is a network-experience monitoring app used on company and agreed pilot devices. It measures mobile and Wi-Fi network quality — it is designed to measure network performance, not to monitor the people using the devices.

Data collected during a test

  • Network performance: download speed, upload speed, latency, and latency while the connection is busy.
  • Connection type, mobile network generation, and carrier name where the operating system provides it.
  • On Android only: serving-cell radio details (signal strength, cell ID, PCI, TAC, frequency, timing advance, network codes) where the device and permissions allow.
  • Device model, operating system version, app version, and a randomly generated anonymous device ID.
  • Location at the time of each test. Coordinates are rounded to roughly 110 metres and accuracy is floored to 100 metres before the reading ever leaves the device.
  • An optional note the user can type in when running a manual test.

Data not collected

  • Names, email addresses, or account logins.
  • Messages, calls, contacts, or browsing history.
  • App usage outside GridPulseCX.
  • Continuous location tracking — location is only captured at the moment of a test.

How data is used

Results are saved on the device and, when enabled, uploaded to a Google Cloud project (Firestore and BigQuery) that we operate for this pilot. The data is used to understand mobile network experience by area, store, connection type, and device group. It is not sold, and it is not shared with advertisers or other third parties for their own purposes.

How long we keep data

We keep GridPulseCX pilot results only for as long as they are needed to support this pilot. Data is reviewed periodically, and results that are no longer needed for the pilot's analysis are deleted. If this pilot continues or expands beyond its initial phase, a longer-term retention schedule will be published here before that happens.

Your controls

  • Data collection requires accepting the in-app consent screen first.
  • Collection can be paused at any time from the app's admin settings.
  • Local results on the device can be cleared from admin settings.
  • Your anonymous device ID is shown on the device under Settings → Admin → Device. To request deletion of the data associated with your device, contact us (below) with that ID.

Security

Data is sent over encrypted connections (HTTPS). Uploads are authenticated and validated before they are stored; malformed or out-of-range data is rejected.

Children's privacy

GridPulseCX is not directed at children and is not intended for use by anyone under 16.

Changes to this policy

If this policy changes, the effective date above will be updated.
