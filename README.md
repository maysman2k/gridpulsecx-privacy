# GridPulseCX Privacy Policy

This repo hosts a single static page, published via GitHub Pages, so Google
Play Console and App Store Connect have a stable public URL to link to.

It is intentionally separate from the private `GridPulseCX` app repository
and contains no source code, credentials, or project details beyond what's
already shown in the app's own privacy summary.

Source: `index.html` (also mirrored at `privacy-policy.html`).
Live once Pages is enabled: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
